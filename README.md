# 3A 進路ノート

生徒42人の第1〜第8志望、募集要項、入試日程を管理するブラウザーアプリです。元のHTMLからCSS、アプリのJavaScript、内部モジュール、PDF.jsを展開しました。ビルド・外部CDN・APIキー・サーバー側データベースは不要です。

## 起動

1. ZIPを展開し、このREADMEと同じフォルダでターミナルを開きます。
2. Node.js 18以上で `npm start` または `node server.mjs` を実行します。`npm install` は不要です。
3. ChromeまたはEdgeで http://localhost:8000 を開きます。
4. 終了するときはターミナルで Ctrl+C を押します。

Python 3がある場合は `python -m http.server 8000 --bind 127.0.0.1` でも起動できます。HTMLのダブルクリックではなく、HTTP経由で開いてください。

## GitHubへの保存・公開

このフォルダの内容をリポジトリのルートへ追加してコミットしてください。静的ファイルのみで動き、GitHub Pagesにも配置できます。Pagesではブランチのルートを公開先に設定します。`server.mjs` はローカル起動用で、Pages上では実行されません。サブパスでも動くよう相対パスを使用しています。

## 個人情報と初期データ

GitHub用のため、元のHTMLに含まれていた生徒別の志望校・成績・判定・メモ・個別追加方式の指定を収録していません。42人分の出席番号だけの空データから開始します。公表された大学の入試情報と公式リンクは保持しています。元ファイルやGmail画像、個人データのバックアップも同梱していません。

実際のデータは「データ管理」から元アプリのJSONバックアップを復元するか、42人分のCSVを読み込んでください。復元前には現在の内容をバックアップしてください。ブラウザーの保存データはZIPに自動では含まれません。

この配布物にAPIキー・パスワード・認証設定はありません。個人データをリポジトリへ追加しないでください。`.gitignore` は補助であり、全種類の機密ファイルを自動検出するものではありません。

## 主な操作

- 生徒・志望校：氏名編集、最大8志望、学級の一覧、大学・選抜方式の検索。
- 募集要項：PDF・TXT・本文の貼り付け、日程候補の抽出、原文確認後の登録、志望とのひも付け。
- 入試日程：出願・試験・合格発表・手続期限の一覧。
- データ管理：CSVの読み込み・保存、PDFを含むJSONバックアップと復元。

PDFの文字抽出機能と必要な補助バイナリは同梱しています。画像だけのPDFへのOCR機能はありません。大学公式サイトを開く際はネット接続が必要です。入試情報は元アプリの確認時点（2026-10-18）の内容で、公開先の最新情報も確認してください。

## 保存先

編集内容はlocalStorage、取り込んだPDFはIndexedDBに保存します。クラウド同期・認証・アクセス制限はありません。GitHubにコードを保存してもブラウザー内の編集内容は同期されません。

URL・ポート・ブラウザー・端末を変えると保存先も変わります。元の単一HTML版からの移行にもJSONバックアップの復元が必要です。シークレットモードやブラウザーのデータ削除にも注意し、定期的に「すべて保存」でバックアップしてください。

## 構成

```text
shinro-note/
  index.html                 # 画面と個人データを除いた初期データ
  assets/styles.css          # 元のデザイン・レスポンシブ・印刷スタイル
  src/app.js                 # 画面制御とイベント
  src/modules/*.js           # CSV解析、検索、保存などの内部モジュール
  vendor/pdfjs/              # PDF.js本体・Worker・補助データ
  licenses/                  # 同梱ライブラリのライセンス
  server.mjs                 # 依存パッケージ不要のローカルHTTPサーバー
  package.json
  .gitignore
  README.md
```

外部ライブラリの権利表記は `licenses/` と元のHTML内のライセンス情報に保持しています。アプリ独自部分の利用許諾は元の権利者に従ってください。
